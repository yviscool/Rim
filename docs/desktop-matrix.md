# 真实桌面兼容矩阵 (P2-13)

headless 探针 (`tools/probe_desktop_matrix.ahk`) 只覆盖数学与协议存在性。
以下必须真机手工验证，每项打勾后记构建号与日期。

| # | 场景 | 步骤 | 通过标准 |
|---|---|---|---|
| 1 | Explorer | 重命名框/搜索栏打字 | 输入态识别，不进 vim 分发 |
| 2 | TotalCommander | 双面板切换，`i` 菜单回车/Esc | 菜单可用，焦点回原控件 |
| 3 | 浏览器 | 地址栏手势 | 未绑定手势透传，不吞右键 |
| 4 | 终端 (WT/Console) | 输入框按 `3`/`j` | 零经过 Rim，直接透传 |
| 5 | 文件对话框 #32770 | 另存为框路径提取 | CurrentDir 非空 |
| 6 | 提权窗口 | 管理员记事本按键 | 只读透传，不 Send 注入 |
| 7 | 睡眠唤醒 | 睡眠→唤醒后手势+热键 | 钩子/定时器存活 |
| 8 | 多屏 | 副屏 (-1920) 菜单弹出 | 菜单在可见屏，钳制生效 |
| 9 | DPI 125%/150% | 同上 | 坐标按比例换算，无偏移 |
| 10 | 中文 IME 组字 | 映射窗开中文输入法组字中按映射键 | 组字不碎，键直达程序（`ImeComposing` 守卫；探针盲区，手工验） |
| 11 | 提权窗口 | 管理员程序的对话框按键 | 只读透传；`Send` 受 UIPI 限制可能丢键，重要操作请提权运行 Rim |
| 12 | 自家窗口 | 配置中心/手势 UI 编辑框打字（配了 `[global]` 字母映射时） | 无劫持（进程守卫；`probe_input_guards`） |
| 13 | 浏览器 Vim | Chrome/Edge/Firefox 下 `i`/`Esc` 模式提示、`?` 键表、`f` 穿透到 Surfingkeys | 提示 600ms 自消；`f` 不触发 Rim 动作 |
| 14 | Everything | 搜框打字、`i` 聚焦搜框、结果区 `j/k` | 搜框畅打（Edit 透传）；`i` 一次聚焦（ClassNN 漂移则回退 Shift+Tab，记版本） |
| 15 | Excel | 公式栏/单元格编辑中打字、`Esc` 退出编辑、未映射字母 | 编辑态零劫持（EXCEL6 守卫）；normal 下裸字母被吞不进单元格；`Esc` 切回 normal |
| 16 | PDF | Sumatra 查找条打字、福昕窗口匹配 | 查找条透传；福昕命中窗口名（`Pdf_Foxit`/`Pdf_FoxitNew` 二选一，记 exe 名） |

输入注入策略结论：保持现有 `SendInput` + 菜单透传直调，不引入驱动级注入。
（UIPI 下投递失败即透传，见 Engine 菜单透传与 Hook BeginRelay。）
