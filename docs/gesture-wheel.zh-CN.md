# 滚轮手势：切任务栏窗口 / 调系统音量

[English](gesture-wheel.md) · [返回文档索引](README.md) · [简体中文指南](README.zh-CN.md)

按住手势触发键（默认鼠标右键）不放，再滚动滚轮，可以做两件事。短按触发键仍是普通点击，不受影响。

## 一、右键按住 + 滚轮：前后切换任务栏窗口

| 操作 | 默认动作 |
| --- | --- |
| 按住右键 + 上滚 | 上一个任务栏窗口（`<SP_TaskPrev>`） |
| 按住右键 + 下滚 | 下一个任务栏窗口（`<SP_TaskNext>`） |

行为说明：

- 按任务栏口径取窗口并循环切换，可以绕回；**最小化的窗口会自动还原**（而不仅是在任务栏图标上闪一下）。
- 1.5 秒内连续滚动沿用同一窗口列表，每滚一格前进一步；停顿超过 1.5 秒后重建列表，从当前活动窗口接着切。
- 切换时悬浮显示目标窗口标题（受"显示手势提示"开关控制）。
- 松开右键后本次切换结束，不会弹出右键菜单。

## 二、右键按住 + 点一下左键 + 滚轮：调系统音量

1. 按住右键不放。
2. 点一下左键（这次点击不会穿透到下层窗口），看到"音量模式"提示。
3. 松开左键，滚动滚轮即调系统音量，可连滚；按住左键边按边滚也一样。
4. 松开右键退出音量模式，不会触发笔画手势，也不会弹出右键菜单。

注意：

- 只点了左键、没滚轮就松开右键时，走原来的逻辑（笔画手势正常结算，`L`/`R` 画笔加左键仍是切换窗口）。
- 调音量期间静止多久都不会触发"静止自动取消"（`CancelDelay`），手势轨迹和识别提示也会让位，不会互相打架。
- 不想要这个行为时，把 `[Gesture] VolLatch` 设为 `0`（或在手势管理 → 设置里关掉"启用音量锁存"），左键即恢复直通。

## 三、自定义

滚轮手势和其他手势一样，只是手势名固定为 `WheelUp` / `WheelDown`（可加 `CTRL+` / `ALT+` / `SHIFT+` 前缀），在 `[Gestures]` 或应用层里改动作即可：

```ini
[Gestures]
WheelUp=<SP_TaskPrev>
WheelDown=<SP_TaskNext>
CTRL+WheelUp=<SP_VolUp>
CTRL+WheelDown=<SP_VolDown>
```

手势管理器里同样可以增删改这些绑定，保存即时生效。任务栏切换、音量加减、静音对应的动作名是 `<SP_TaskNext>`、`<SP_TaskPrev>`、`<SP_VolUp>`、`<SP_VolDown>`、`<SP_Mute>`。

相关 `[Gesture]` 开关：

| 键 | 含义 |
| --- | --- |
| `ShowOSD` | 显示手势提示（识别结果、滚轮动作、音量模式等悬浮文字），`0` 关闭后全程静默 |
| `VolLatch` | 音量锁存总开关，`0` 关闭 |
| `NoMatch` | 无法识别时：`swallow` 忽略这一笔 / `passthrough` 模拟一次点击 / `sound` 提示音 |
| `CancelDelay` | 按住静止超过该毫秒数则取消手势（调音量/缩放期间不取消），`0` 关闭 |
| `Trigger` | 触发键：`RButton` / `MButton` / `XButton1` / `XButton2` |

## 四、排查

- **滚轮没反应**：先确认触发键是否一直按住；再看窗口是否命中 `[GestureBlacklist]`，或应用层设置了 `noglobal=1` 覆盖了全局绑定；也可用手势管理的演练模式看识别结果。
- **切不到某个窗口**：无标题窗口、托盘/桌面宿主窗口、子对话框和 DWM 隐藏窗口不在切换列表里。
- **音量和笔画冲突**：确认 `VolLatch=1`；若右键会话内左键需要直通（如某些游戏），设为 `0`。
